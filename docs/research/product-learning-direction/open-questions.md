## Deferred Knowledge candidates — EX-PLD-10 (research only)

These are candidates for **later** semantic testing, not an admitted Prep ontology, fixed taxonomy, or new experiment. Current Prep owner input already requires explicit K–K relation types; it does **not** select their vocabulary.

- **Knowledge classification candidate:** optional `kind` (broad referent form), `areas` (multiple topic memberships), `facets` (subject-specific browse dimensions). The Knowledge Graph V2 pilot used kinds `artifact`, `construct`, `mechanism`, `model`, `pattern`, `practice`, `problem`, `property`, `result`, `structure`, `technology`. Classification does not itself create subject relations; applicability to Prep remains untested.
- **K–K relation candidates for later scrutiny:** `specializes` (more specific kind), `part_of` (genuine part/whole), `depends_on` (necessary prerequisite, not generic relevance), `realizes` (concrete realization of an abstraction). `specifies_guarantee_for` is a **new Prep research hypothesis** motivated by cases such as Consensus Safety vs Distributed Consensus; it is not a historical Knowledge Graph admitted type.
- **Other historical candidates to revisit only if needed:** `enables`, `produces`, `derives_from`; broader vocabularies require their own evidence. `uses` historically meant *functional employment* but is considered too broad/low-information for the **initial Prep shortlist**. Do not automatically replace every `uses` example with `realizes`: using a mechanism is not the same as implementing an abstraction.
- **Test for later admission:** precise meaning and direction, permissible endpoints, supported positive and adversarial negative examples across diverse Knowledge kinds, and concrete Prep navigation value. A useful explanatory link or shared facet is not automatically an admitted typed K–K assertion.

**Current stopping point / next priority (after K–K desk review):** Standards and K–K counterexample evidence are consolidated in `findings.md`; no K–K leaf has been owner-admitted. Obtain owner choice on a minimal typed **research fixture**, not a complete taxonomy. Keep Knowledge kinds/facets/depth and generic pedagogical dependencies deferred; independently finish the existing G–C/C–K/K–M lifecycle and Activity/Result open questions, then verify the corrected EX-PLD-10 fixture against EX-PLD-11.
