# Prep — Capability / Goal semantics

This research topic examines how Prep can represent goal-oriented preparation through **Goal**, **CapabilityDescription**, **Knowledge**, **PracticeMaterial**, and recorded **Activity/Result**. It explores what different relationships actually mean, how incomplete information can be refined, and whether Capability composition is distinct from execution order, prerequisites and procedures.

The main domain question is how a person can start with an incomplete Goal, examine relevant abilities and supporting information, practise outside Prep, return to the Goal with recorded results, and choose what to work on next—without assuming an automatic mastery engine or a fixed task sequence.
