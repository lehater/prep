# Prep research workspace

The `docs/research/` directory collects noncanonical research about Prep: domain questions, alternative interpretations, counterexamples, bounded experiments and findings. It lets future contributors reuse evidence across conversations and avoid repeating earlier analysis.

Research evidence is distinct from Prep's canonical engineering knowledge. Decisions and approved product/domain semantics are managed by the owning Authority and Harness, not by these notes.

## Topics

- [Capability / Goal semantics](capability-goal-semantics/README.md) — Goal-first preparation, Capability descriptions and decomposition, relation meanings, and activity/result context.

## Navigation

- [Local agent index](AGENTS.md) — where an automated contributor finds relevant instructions.
- [Research working procedure](WORKFLOW.md) — how to preserve, test and hand off research.
- Each topic README explains its subject and links to evidence; the topic handoff and question/experiment lists hold evolving work state.

Runnable demonstrations and technical spikes may live under repository `experiments/`, but research does not inherently require code or a frontend.
