# Prep research

This is a **noncanonical** workspace for current questions and bounded evidence, not an alternative engineering knowledge graph. The engineering baseline is the accepted Harness publication and the artifacts registered by `.harness/core.yaml` on `mvp-vertical-slice`.

Start at [the active topic](product-learning-direction/README.md) and [research guidance](AGENTS.md). Research does not silently alter accepted requirements, strategic classification, or domain entities. The current information-model and interface studies are **separate** until their compatibility is tested.

Only actionable current conclusions and unresolved questions are kept here. Older iterations, invalid candidates, superseded fixtures, and duplicate status lists are not part of the active documentation.
