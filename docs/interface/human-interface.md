## Current synthesis

Prep has two explicit task modes:

- **Learning** — select a prepared LearningTarget and use Overview, Knowledge, Study and Statistics;
- **Curation** — maintain Targets, Knowledge, Requirements/RequirementSets, Questions and their accepted relationships.

The same physical user may switch modes in v1; they are task contexts, not authentication roles.

Learning target scope is curated and read-only in Learning. Knowledge Graph is a first-class experimental representation for relational exploration/learning, but every core Knowledge task remains available without graph manipulation.

The site/app map is a projection of canonical Interface Topology. Detailed interaction behavior, view responsibilities, presentation rules and unresolved 3D-learning hypotheses live in their respective canonical/interface research documents.
