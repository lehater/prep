# Preparation Process

## Purpose

Provide a repeatable closed-loop process for technical interview preparation.

## Flow

```text
Target role
  -> interview/competency model
  -> question pool
  -> baseline assessment
  -> gap map
  -> targeted learning
  -> retrieval/spaced practice
  -> reassessment
  -> mock interview
  -> error analysis
  -> updated gap map
```

## Baseline assessment

The first pass is diagnostic. Questions are attempted before targeted study so the project captures a useful starting point.

Baseline attempts must remain distinguishable from later review attempts.

## Learning loop

For an observed gap:
1. identify the affected `Concept × LearningTask`;
2. study or clarify the concept;
3. add or refine targeted questions if needed;
4. practice retrieval through the execution adapter;
5. reassess after spacing;
6. update the gap state from evidence.

## Anki role

Anki is initially the primary execution environment for:
- presenting prompts;
- recording review outcomes;
- scheduling repeated retrieval.

It does not define the domain model or the meaning of mastery.

## Error analysis

Failures should be classified before choosing remediation. Candidate classes include:
- missing knowledge;
- weak mechanism understanding;
- comparison/selection failure;
- application failure;
- debugging failure;
- communication failure;
- time-management failure.

Different failure classes should result in different learning actions.
