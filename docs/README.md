# Prep canonical engineering knowledge

The engineering source of truth on this branch is the accepted Harness publication and the artifacts registered in `.harness/core.yaml`, under the ownership and dependency graph `.harness/engineering-graph.yaml`.

Read `AGENTS.md`, then follow its pinned Harness procedure to inspect the current graph, Core Questions, Publication and the smallest set of accepted artifacts required for a **canonical engineering** change.

All other materials, especially [research](research/README.md) and experiments, are **noncanonical evidence**. They do not override accepted Product Requirements, Domain Strategy or tactical decisions, and do not define acceptance/currentness. Unresolved canonical semantic choices are handled by the owning Authority and Harness Core Questions.

Repository documentation validation must identify any unregistered canonical files. No removed legacy engineering document is a source of active Prep semantics.
