# Prep Product Capabilities — reference

> **Noncanonical navigation page.** This file is not a second source of
> product capabilities or their acceptance evidence.

The current, accepted set of externally observable capabilities is in
[the canonical PRODUCT-CAPABILITIES artifact](../../.harness/knowledge/product-capabilities.yaml).
Read `content.requirements` for accepted versus retired proposals,
`content.intent_coverage` for links to accepted Product Intent, and
`content.scope_boundaries` for explicit implementation-independent scope.

The authoritative acceptance/currentness state is the
[published Harness state](../../.harness/project-publication.yaml).
For governed work, begin with [AGENTS.md](../../AGENTS.md) and the
[documentation index](../README.md).

The superseded text formerly included capabilities for inferred learner
state, target-relative assessments and other behavior not accepted for
the current MVP. The old statements are **not CURRENT**, even if a
historical version of this page labels them ACCEPTED.

Do not maintain a copied list of requirements in this noncanonical page.
Change capabilities only through the owning Harness procedure and its
canonical PRODUCT-CAPABILITIES artifact.
