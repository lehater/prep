# Interface Verification

## Purpose

Define evidence needed to validate accepted Task Model, Information Architecture, Interaction Design and Interface Topology before detailed frontend realization.

## Current executable checks

The pinned Harness integration must prove:

- every current USER task has an Interaction Design context or explicit no-UI disposition;
- every interaction context resolves to accepted Information Architecture;
- every interaction context maps to at least one topology view or explicit non-view disposition;
- every USER task therefore reaches a topology view;
- topology parent/exit references resolve;
- the topology-derived required view set is complete enough to drive Screen/View subject coverage.

Findability/usability testing such as tree testing or task-based prototype evaluation remains future evidence where material. Findings route back to HUMAN-INTERFACE-DESIGN rather than changing interface truth here.
