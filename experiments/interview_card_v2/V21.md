# Prep Card v2.1 — learner-first presentation

`v2.1` is a presentation-only experiment over the same 14 semantic learning objects used by `v2.0`.

It exists to compare information architecture, not to test new content.

## Isolation

```text
v2.0
  NoteType: Prep Learning Object v2
  Deck:     Prep::Prototype v2

v2.1
  NoteType: Prep Learning Object v2.1
  Deck:     Prep::Prototype v2.1
```

Both projections read:

```text
experiments/interview_card_v2/prototypes.json
```

Applying `v2.1` does not modify or delete `v2.0` notes.

## Presentation rules under test

Front:

```text
Тема: <learner-facing concept label>
Контекст: <real subject context, optional>

<stimulus, optional>

<prompt>

Формат ответа: <human-facing guidance>
```

Normal learner-facing front does not expose:

```text
KnowledgeKind
LearningTask
QuestionType
GuidanceLevel
StimulusFormat
raw ResponseFormat
PrototypeId
```

At most one optional interaction cue is shown when it materially changes interpretation, for example:

```text
Разобранный пример
Диагностика
Проектирование
Анализ кода
```

Back hierarchy:

```text
Быстрая проверка
  Краткий ответ
  Ключевые пункты

Разбор
  Объяснение
  Ход рассуждения
  Эталонный вариант

Дополнительно
  Типичная ошибка
  Альтернативы
  Источники
```

## Local use

With Anki Desktop and AnkiConnect running:

```bash
python -m experiments.interview_card_v2.sync_v21
```

Then apply:

```bash
python -m experiments.interview_card_v2.sync_v21 --apply
```

Expected first apply:

```text
created: 14
```

Expected second unchanged apply:

```text
unchanged: 14
```

## Comparison checklist

Compare `Prep::Prototype v2` and `Prep::Prototype v2.1` for the same prototype IDs.

Check:

1. Is `Тема` immediately distinguishable from `Контекст`?
2. Does `Payment API` now read as context rather than a subtopic?
3. Does `Формат ответа` read as an instruction rather than an answer?
4. Is removing `apply / scenario / independent` an improvement in scanability?
5. Is one optional interaction cue enough where orientation is genuinely needed?
6. Is stimulus-before-prompt more natural for scenarios and code-tracing tasks?
7. Can the answer be self-checked quickly from `Краткий ответ + Ключевые пункты`?
8. Does deeper feedback remain easy to scan without dominating the fast check?
9. Are code blocks comfortable on desktop and mobile widths?
10. Which v2.1 label or section is still redundant?

Do not change the semantic dataset based on styling preference alone. Record separately whether a problem belongs to content semantics or presentation.
