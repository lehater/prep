# EX-PLD-06 · локальный интерактивный прототип

Некоммерческий, автономный исследовательский инструмент, не продукт Prep и не результат пользовательской проверки. Использует **только** существующий `../fixture.json`; зависимости npm отсутствуют. Требуется Node.js 20+ и Python 3 для исходного fixture-check.

## Запуск из свежей копии репозитория

```bash
cd experiments/prep_study_loop/prototype
npm run dev
```

Открыть **один** из URL: `http://127.0.0.1:4173/?arm=A`, `...?arm=B`, `...?arm=C`. Режимы выбирает оператор адресом, участнику переключатель не показывается. Нейтральный справочный лист для **D**: `http://127.0.0.1:4173/handout.html` (используется с реальными внешними инструментами, не как четвёртый UI). Подсказки оператору — `OPERATOR.md`.

## Проверки, сборка, локальный preview

```bash
# из корня репозитория
python experiments/prep_study_loop/check.py
cd experiments/prep_study_loop/prototype
npm test
npm run build
npm run preview
```

После сборки `dist/` — статический сайт, содержащий `participant.json` и `handout.html` **без** контрольных ответов. Сервер обслуживает только разрешённые пути; исходный fixture и файл оператора недоступны через HTTP. Вариант A содержит навигацию по цели/контекстам/темам без экспорта; B добавляет ручной выбор и TSV; C — плоский каталог и тот же выбор/экспорт без навигатора. Материал типа `scenario` можно отдельно отметить, но он не попадёт в TSV. Любая карточка, даже неуместная, может быть выбрана вручную; выбор не основан на скрытой оценке релевантности.

При выборе под фильтром Cxx метка `cxx` фиксирует **контекст выбора**, не истинность/обязательность материала. В C карточки экспортируются с ID материала, ID тем и ID цели без C-метки. Экспорт — UTF-8 TSV с `Front`, `Back`, `Tags` и исходными формулировками; реальный импорт в Anki не проверялся. Файл `dist/` генерируется локально и **не** коммитится.
